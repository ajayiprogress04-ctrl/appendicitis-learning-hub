# Legend-writing reference applied

Authoritative reference recovered and read in full: **Pasted text(20260930-163940).txt**, supplied 30 September 2026. It contains the four-column scientific-writing instructions and examples for Lab Studies 1 and 2. Its language and organisation are used here; those laboratory findings, age comparisons and Prism analyses are not transferred into the appendicitis study.

Applied rules:
- A concise scientific subject/title, with no generic “Figure showing results” preface.
- Figure content identifies the actual plot, variables, comparison, panels and units where recorded. Panel syntax follows “A, Variable (unit); B, Variable (unit)” when the user adds verified panels. The app does not invent panel letters, units or error-bar definitions.
- A concise observation based on recorded cells/plot values; no inference of statistical significance from appearance.
- A clean description of the actual stored analysis, supplemented by relevant available table statistics. No borrowed test, alpha, exact-test claim, p-value, confidence interval or physiological explanation.
- Software/export audit messages stay in separate editor warnings, outside final legend prose.
- Legends describe content/observations/analysis; interpretations address the research objective and uncertainty. Original computed interpretations remain available until reviewed authored prose is saved.

The writing helper creates deterministic editable drafts from this app's actual result objects. It does not replicate an author's judgment automatically, perform new statistics or assert that every draft is publication-ready. Check every draft against the output and approved protocol before saving it as reviewed. Unsupported information is omitted from prose and identified in the editor's verification checklist.
