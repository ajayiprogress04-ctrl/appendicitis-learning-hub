# Original decorative scientific artwork

Six original SVG motif families, each with coordinated light, dark and colored treatments:
DNA helices; molecular bonds/nodes; cellular membranes/nuclei; schematic intestine/appendix; scientific grids/scatter/matrices; abstract biomedical waveforms.

These assets were constructed for this project from original vector paths and parametric curves. No third-party artwork, external image service or patient recordings are used. Anatomy and molecular structures are decorative schematic compositions, not anatomical teaching references or identified compounds. Waveforms/data points do not represent study findings.

All colour variants share their family's geometry; Colored Mode adds a decorative ECG-inspired trace to the waveform family. The CSS controls placement, scale and text-protection masks. Total SVG source size across 18 assets is 140,960 bytes. There are no scripts, embedded raster images, external resources or animations.
