# Objective-linked workflow update — 16 October 2026

Current primary navigation is Objectives → Reports → Papers. Tables & Figures,
Statistical Glossary, Interpretations and the existing supporting tools remain
secondary. Older validation notes describe historical versions, not this layout.

## Use

Import the private study dataset, select Objective 1–8, choose its outputs and
generate. The corresponding Reports and Papers areas share that selection and
the calculated results. Preview or export the selected report; manuscript titles
remain editable. Existing detailed workspaces remain available in disclosures.

The uploaded reports informed structure, not numerical results. Values are
generated by the existing analysis engine from the active dataset. Generation
progress records completed calculations and names failures; retry preserves
successful results. Word compilation has separate actual item progress.
