# Integrated scientific prose refinement

## Targeted changes
The previous export created separate labelled Results and Interpretation paragraphs, and the app repeated an Interpretation paragraph in the methods detail. One shared narrative formatter now produces one ordinary unlabelled paragraph after output legends, notes and abbreviations. Reports preview, genuine Word export, Tables & Figures and linked Interpretations use that formatter. Exact repeated sentences are removed and paragraph breaks are joined; source writing itself is retained. There are no narrative subheadings or bullet elements.

The formatter uses the existing verified result interpretation rather than repeating every row as a second results list. Demographic and paired confidence outputs also receive concise, schema-specific prose from their actual stored values. No new analysis, p-value, confidence interval, significance claim, diagnostic threshold or clinical effect is generated. Descriptive confidence distributions are not presented as diagnostic performance, professional-group effects or inferential evidence. Other analysis families retain their existing calculated academic interpretation; saved authored interpretations override generated prose. Selected reviewed results text and selected meaning are combined in one paragraph. Different user-written passages may still require editorial review for partial repetition.

Tables retain titles above them. The in-app figure caption was moved below the plot, matching the approved export placement. Notes and abbreviations precede the explanation. The legend editor and interpretation editor remain accessible, and the Interpretations main tab is preserved. The methods detail now explains methods/assumptions without duplicating the narrative. Approved Word typography, margins, table styling, figure aspect ratio and footer are unchanged.

## Use
Extract the complete ZIP, run `python -m http.server 8000` in project and open http://localhost:8000. No API keys or npm installation are needed. Generate outputs locally, review writing, select components in Reports and export Word. Narrative formatting is the default; existing source-change/missing-writing review guards remain. Save/export your work before refreshing because the existing research workspace retains data and writing in memory.
